## 6. 已修复偏差与仍存偏差

### 6.1 V0.1 已修复

| 偏差 | 修复 |
|---|---|
| 匿名故事仍下发真实 `authorId/avatarId/ownerId` | 合成 `anon_<storyId>`；详情/图鉴/事件字段统一脱敏；作者用 `viewerIsAuthor` 判断；赠礼由服务端解析作者 |
| 无法“只自己可见” | `Story.visibility='self'`；发布页开关；图鉴排除；他人 `NOT_VISIBLE`；分享隐藏 |
| V0 要求的状态贴纸未做 | `HotspotSummary.sticker` + 图鉴/WXML/预览渲染 |
| 互动按动作各 3 次（最多 9 次/日） | 改为抱抱/转圈/鼓掌合计 3 次/日，文案/组件/预览同步 |
| 新故事默认允许搞笑动作 | 默认关闭，作者手动打开；`settings` 全局开关仍生效 |

### 6.2 仍存偏差（明确不在 V0.1 修）

- 发布没有 `draftId/revision`；草稿与编辑重审在 V1。
- 邀请 token 可过期/限次，但没有撤销列表和审批状态。
- 匿名仅脱敏 ID，保留头像外观；小群内仍可能通过外观识别（V1 隐私决策）。
- `requestId` 只用于 `publish/gift/claimWeekly/react`；`withdraw/avatar/settings/join` 靠语义或版本锁保证幂等。
- 错误码在方案基础上扩展了 `INTERACTION_DISABLED`、`VALIDATION_FAILED`。
- 默认展示“全部”而非“本周”；周口径统计函数已实现。
- 实际交付 8 条故事 / 3 个圈子 / 4 个动作，高于方案 V0 的 5/2/3。
- 热点为正面 11、背面 12；方案要求 10–12，满足。
- 预览是独立 DOM 实现，不等于微信原生组件与真机性能。
