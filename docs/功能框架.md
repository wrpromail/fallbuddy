# 摔友记功能框架

2026-11-21 工作区版本。以小程序页面和业务接口作为验收入口。浏览器预览覆盖换装和互动，独立解剖网页覆盖图版和动作示意。

| 功能 | 用户从哪里进入 | 当前实现和验收要点 |
|---|---|---|
| 创建事故 | 图鉴「记录一次」、角色页「新建事故记录」 | 结构化填写运动、背景、原因、身体部位、情况和护具，可选日期与自述。可存私人草稿、继续编辑、选择受众、匿名发布。 |
| 更新与回访 | 故事详情、消息 | 作者能修改、撤回、永久删除和追加后续。编辑冲突保留输入。追加后续时按所见版本提交，另一台设备改变受众后须核对再提交。圈友可关注或取消关注，消息页只展示仍有权限阅读的后续。 |
| 身体图 | 图鉴、事故表单、故事详情、独立解剖网页 | 标准骨骼、浅层肌肉共用同一参考模型的正背图与定位点。选中部位会显示对应骨性标志或软组织说明。尾骨从背面定位。网页可并排对照四图并打开原图。Q 版和可动示意用于互动。 |
| 创建与保存形象 | 我的角色 → 编辑形象与穿搭 | 可组合头型、表情、主色、八个装备位，预览正面、背面、小头像和动作。可收藏三套已保存的形象。收藏带版本，试穿收藏或随机搭配后可保存或取消。 |
| 装备与背包 | 我的角色 → 衣橱、背包 | 永久外观免费领取。有效的互动护臀可由本人试穿，收到礼物后穿搭保持原样。使用或赠出最后一件会卸下，过期后也停止展示。消耗操作核对库存版本并按请求去重。 |
| 同款经历 | 圈内故事详情 → 查看或关联同款经历 | 从自己在同圈的可见故事中选一条。对方在消息或详情确认后，圈友可双向阅读。双方都能撤销，同一对故事只建立一次。取消、拒绝或移除该圈受众后，本版结束这对故事的关联。 |
| 评选与纪念章 | 圈子 → 圈内故事评选 | 三种奖项按北京时间自然周独立计票。圈主提名，作者同意后圈友才能投票。每人每奖项一票，同票同名次。可查往期，圈主可提前结束单个奖项，作者可退出评选。首投获得一枚永久展示纪念章，角色背包可见。 |
| 语音起草 | 事故表单 → 故事正文 → 用语音起草 | 主动授权后录音 15 至 90 秒，可回听、手动摘录或丢弃。自动转写须单独同意并启用服务端适配器。结果可修改，采用后只填入表单。原文提到的部位、护具、场景须逐项确认。 |
| 圈子与隐私 | 圈子、消息、设置 | 建圈、审批、撤销邀请、转让、退圈及历史受众选择已实现。支持举报处理、双向屏蔽、忽略互动、匿名展示、隐藏个人形象、删除故事和注销账号。 |
| 互动 | 故事详情、消息 | 抱抱、鼓掌、转圈、赠礼和回放复用角色图层，支持减少动效。圈主和管理员可暂停本圈互动和赠礼。 |

## 数据与接口

| 领域 | 主要方法 | 约束 |
|---|---|---|
| 后续 | `story.appendUpdate / setFollow / followedUpdates` | 新端追加时传 `expectedVersion`。旧端可沿用原签名。关注以用户、圈子和故事区分，消息页展示最近 50 条可见后续。 |
| 形象和库存 | `avatar.listOutfits / saveOutfit / updateAppearance`、`inventory.consume / gift` | 穿搭收藏只从服务端读取本人已保存的外观。使用收藏时再次校验现有库存。周补给和赠礼检查堆叠上限。 |
| 关联 | `links.list / request / requests / decide` | 关联绑定发起时的圈子。读取时重查两条故事、双方成员身份和屏蔽关系。请求列表只对被邀请作者可见。 |
| 评选 | `poll.list / change / close / myBadge` | 按圈子、周、奖项和投票人去重。候选只返回故事标题、去标识的票数和当前用户可执行的操作。 |
| 语音 | `voice.available / open / run / cancel` | 服务端先占额度，再在事务外调用处理商。取消后丢弃迟到的结果。数据库仅存任务状态、时间及标识，发布仍走同一事故表单。 |

## 已验证和待验证

- 本地自动化覆盖旧数据兼容、事故冲突、圈子权限、穿搭与库存、参与评选、关注和同款的可见性。模拟云端测试使用打包后的业务代码，覆盖并发、取消、额度和事务回滚。
- 可复现命令为 `npm run verify`、`npm run test:cloud`、`npm run preview:qa`、`npm run anatomy:qa`。后两项需要 Chrome。新圈内玩法和语音主流程测试走原生页面事件、组件与服务接口。
- 标准图的解剖精度仍需逐图专业复核。微信原生录音编码、麦克风权限、动作低动效、双设备断网重试和 CloudBase 实际耗时仍需真机验收。[标准图复核要点](../miniprogram/assets/anatomy/NOTICE.md)
- 自动语音整理已接入兼容转写和对话接口。本轮通过替身验证任务合同。真实中文口述质量、处理商数据保留、实际开销和超时须在选择处理商后验证。当前任务结果在本次请求中交付，跨设备恢复未采用的转写稿、断线后续取结果和定时清理历史任务元数据仍待开发。[语音服务参数](../cloudfunctions/fallbuddy/README.md)
- 扩展项仍包括按圈单独设置形象可见性、账号数据导出、举报申诉流程和匿名汇总使用统计。上述项目可独立迭代。
