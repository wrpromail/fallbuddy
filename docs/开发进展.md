# 摔友记 · 开发进展

> 进度快照 + 版本历史 + 待办 + 里程碑。对照基线是方案 §16 的 V0 → V1 → V1.1 → V1.2 路线。

## 当前交付（2026-11-21）

事故创建与更新、角色和装备、标准人体图、关注后续、同款经历、圈内评选和纪念章均有原生入口。口述支持授权录音、回听、人工确认，自动转写和文字整理可通过云函数适配器启用。正文与语音建议不会自动发布。

本轮新增了追加后续时的受众版本核对、三套穿搭收藏、随机试穿、消耗及穿戴互动护臀、隐藏形象、同款确认与撤销、按圈按周投票。小程序显示选中部位的骨性标志或软组织说明，独立解剖网页可对照四张标准图。

本轮通过 56 项项目测试、18 项模拟云函数测试、25 项浏览器预览检查和 38 项解剖网页检查。类型、数据 Schema、87 个角色图层和小程序模板检查通过。语音处理商在自动化中使用替身。

按用户操作核对完成度、接口变化和待办，见[功能框架](功能框架.md)。

## 前三阶段交付记录

- 事故已支持私人草稿、发布、编辑、追加及撤回后续。标准骨骼和浅层肌肉各有正背图，图鉴、创建页和详情页共用部位和侧别。
- Q 版角色首版已支持 2 种头型、5 种表情、4 种主色、5 个装备位、8 件永久外观和正背面、头像预览。初始装备只发放一次，老用户继续使用原有装备。匿名故事统一显示昵称和形象。
- 第一阶段已实现单圈子邀请审批、文本审核和举报处理。测试环境配置和微信真机验证待完成。

### 第三阶段装备（2026-11-21）

- 衣橱新增手套、护膝和手持三个装备位，以及四件可免费领取的永久外观。旧角色更新后保留穿戴。单板默认为右手，可在正面或背面预览实际侧别。雪杖由双手分别握持。
- 抱抱和鼓掌时暂时收起手持装备，手套随手臂运动。转圈时器材随角色一起移动。减少动效时保持静态握持。
- 该阶段建立了八槽穿戴基础。本轮的收藏、关联、评选和语音实现见页首。

### 第二阶段

- 作者可永久删除事故和关联记录。云端账号可立即注销，已到账礼物随接收方保留。匿名设置说明已与页面展示同步。
- 支持创建和切换圈子、撤销邀请、转让圈主。退圈时可选择是否保留此前发布在该圈子的故事。
- 消息按故事、自然日和动作合并，可展开回放、忽略或屏蔽。圈主和管理员可暂停互动、赠礼，圈内故事仍可阅读。
- 云端已按领域拆分存储，旧文档可在事务中迁移。自动化覆盖迁移回滚、跨分区读写、可见范围、库存和流水。真实环境的迁移、性能及真机验收仍待执行。[部署与验收步骤](../cloudfunctions/fallbuddy/README.md)

## 8. 基础组件 01：解剖战损人体（anatomy-web/，2026-11-20）

小程序「Q 版骷髅图鉴」的解剖级升级，独立网页组件先行（`npm run anatomy` → http://localhost:7788）。定位：给后续「可动人体 + 战损分布 + AI 解说」类需求打地基，数据与渲染分离，小程序/3D 都是它的消费方。

| 模块 | 交付 |
|---|---|
| 人体数据 | 14 个解剖区域结构化卡片（骨骼/肌肉与分工/协作方式/常见损伤）——同时是 AI prompt 的事实来源，防幻觉 |
| 双风格画法 | **标准解剖**（约 7 头身：颅骨眶/鼻切迹/下颌、颈椎、9 对肋 + 胸骨三段、真骨盆、带骨骺长骨、腕-掌-指分节；肌肉按起止走向）+ **Q 版骷髅**（4 头身，与小程序角色同调性），同一接口一键切换 |
| 运动 | 16 关节嵌套分组；待机呼吸/重心晃动程序化；挥手/摔倒回放/9 个部位演示为关键帧插值，**角度按各风格肢体长度分别校准**（标准版手臂长，挥手改肘部带动） |
| 分布与注入 | 受伤热力 5 档 + 部位徽标；表单与 `POST /api/records` 双通道，记录持久化 `anatomy-web/data/`（gitignore，种子自动生成） |
| AI | 流式（SSE→分块转发，实测首包 ~1.8s/52 片）；讲解/部位调侃/全群吐槽三种 prompt；调侃强制「只损行为 + 结尾安全提醒」，匿名记录进 prompt 前脱敏；无 key 降级模板同样打字机流出并标注 |
| 回归 | `npm run anatomy:qa` 36 项：服务面/结构面/双风格像素采样（冻结动画→光栅化→实心形状内部取色，不依赖肉眼）/交互面/流式降级；截图 `preview/screens/anatomy-*.png` |

完整 API 表、配置（`OLLAMA_API_KEY` 读取顺序）与接入路径见 [anatomy-web/README.md](../anatomy-web/README.md)。
